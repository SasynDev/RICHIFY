## 🚀 Overview

**RICHIFY** is a modern, high-performance, and deeply customizable Discord Rich Presence utility for Windows designed and developed by **SasynDev**. It features a frosted glassmorphism interface, ultra-smooth motion feedback, seamless in-place background updates (no console popups), and complete control over your Discord profile presence.

---

## ✨ Features

- 💎 **Modern Glassmorphic UI**: Ultra-clean frosted obsidian theme with dynamic ambient atmospheric glow.
- ⚡ **Ultra-Smooth Interactions**: Fluid button hover and press motion animations with anti-aliased visual rendering.
- 🔄 **Silent In-Place Updater**: Automatically downloads new updates, atomic NTFS binary swap, and restarts instantly without annoying CMD or BAT popups.
- 📦 **100% Standalone Portable**: Single self-contained executable with all dependencies and multi-language satellite assemblies embedded—works anywhere.
- 🎯 **Privacy-First**: No telemetry popups or blocking prompts; runs quietly and efficiently.
- 🎨 **Full Presence Control**: Custom details, state, live elapsed/remaining timestamps, party counters, large/small asset keys, and interactive custom buttons.
- 🌐 **Multi-Language Support**: Fully localized into dozens of languages.
- 💻 **Tray Minimization & Auto-Start**: Runs smoothly in the Windows system tray with zero background overhead.

## 🛠️ Getting Started

### Requirements
- Windows 10 or 11 (Windows 7/8.1 supported via .NET 4.8)
- .NET Framework 4.8
- Discord Desktop Client

### Building from Source
1. Clone the repository:
   ```bash
   git clone https://github.com/SasynDev/RICHIFY.git
   ```
2. Open `RICHIFY.sln` in Visual Studio 2022+ or build via Developer Command Prompt / MSBuild:
   ```cmd
   msbuild RICHIFY.sln /p:Configuration=Release
   ```
3. The single-file bundled executable will be generated at:
   ```
   CustomRPC\bin\Release\RICHIFY.exe
   ```
